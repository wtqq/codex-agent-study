# Codex Agent 学习计划

本目录用于系统掌握 `openai/codex` 的架构设计，并把每一阶段学到的东西沉淀下来，方便后续向团队分享，也为团队自研 agent 提供设计参考。

## 使用流程

1. 每次学习开始时，先打开 `PLAN.md`，确认当前阶段和下一步动作。
2. 学习过程中把新认知写进 `KNOWLEDGE.md`，按模块或主题追加，不要只留在聊天记录里。
3. 每次学习结束时，在 `SESSION_LOG.md` 追加一条记录：日期、阶段、做了什么、关键收获、遗留问题、下一步。
4. 完成某个交付物后再勾选 `PLAN.md` 里的 checklist，避免“看过就算学会”。

## 文件说明

- `PLAN.md`：阶段计划、阅读清单、交付物、完成状态。
- `KNOWLEDGE.md`：知识库，按架构层和模块沉淀职责、场景、交互、关键文件。
- `SESSION_LOG.md`：学习会话日志，防止遗忘进度和问题。

## 基本原则

- 每个模块至少能回答四个问题：做什么、什么场景用、和谁交互、关键代码在哪。
- 每个阶段结束前，把能讲给同事听的一句话总结写进 `KNOWLEDGE.md`。
- 疑问先记进 `SESSION_LOG.md`，不要中断主线太深。
